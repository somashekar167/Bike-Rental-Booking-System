# Bike Rental Management System

## 📌 Overview
The Bike Rental Management System is a web application that allows users to browse available bikes, rent bikes for a selected duration, and manage bookings online. The system provides an easy-to-use interface for customers and administrators.

## 🚀 Features

### User Features
- User Registration & Login
- Browse Available Bikes
- Search and Filter Bikes
- View Bike Details
- Rent Bikes Online
- Booking History
- Profile Management

### Admin Features
- Admin Login
- Add/Edit/Delete Bikes
- Manage Users
- Manage Rentals
- View Booking Records
- Dashboard Analytics

## 🛠️ Technologies Used

### Frontend
